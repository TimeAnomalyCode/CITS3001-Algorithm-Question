"Sco bo tro no flo jo ko fo to do. No bo ho sho ko ro to so. Bokodozogobofopojo. Ma ho."
\begin{flushright}
    --- Famous alien from a Blue Box, 2008. \\
\end{flushright}

You are a translator that was sent out into deep space to study a new alien language. You have been entrusted with a small dictionary with some alien words that are known to you. The first entry of the dictionary is blank.The alien language uses a 2D structure to represent their language as some sort of cost-saving measure. \\

Each letter is a branch to another letter. When the branch ends, that is considered a word. Each word may be repeated more than once. Some words are considered special as they end with \code{.}  or \code{+}. There is only one word that ends with \code{.} but there are multiple words that end with \code{+}. \\

There is one problem, your radio antenna has low bandwidth which means simply sending the word back to Earth will take too long. You will have to return a coded message using the index of your on board dictionary. \\

The coded message is prefixed with digit \code{0}. Any valid word index is appended to the coded message and must be sorted. Once all words have been appended, any valid word that ends with \code{+}, the index should be added to the prefix. Additionally, the valid word that ends with \code{.}, the index should be appended to the end of the coded message.

\section*{Input}
\begin{flushleft}
    The first line contains N, R, D ($1 \leq N \leq 10^6$, $1 \leq R \leq 10^6$, $1 \leq D \leq 500,000$) where N is the number of nodes, R is the number of relations, D is the number of words in the dictionary. \\
\end{flushleft}

\begin{flushleft}
    The second line contains the words sorted in the dictionary. The third line contains the start node and the letter of the alphabet. \\
\end{flushleft}

\begin{flushleft}
    The following lines is based on the number of relations where Line A (for A = 0, 1, ..., R - 1) has 3 values. The values are source node, destination node and value. The value is alphabetic and capitalized or \code{.} or \code{+}. \\
\end{flushleft}

\section*{Output}
\begin{flushleft}
    Output a coded message. \\
\end{flushleft}

\begin{flushleft}
    The format of the coded message starts with \code{0}. The following digits are the index of all valid words sorted. The index is based on the dictionary where the first entry is blank. The end of the coded message is the index of the valid word that ends with \code{.} and is guaranteed to have a unique path (\href{https://en.wikipedia.org/wiki/Collider_(statistics)}{No Colliders}). The words can only end with \code{.} or \code{+} but not both together. \\
\end{flushleft}

\begin{flushleft}
    Any valid word that ends with \code{+} has their indexes sum to \code{0} at the start of the coded message. \\
\end{flushleft}
